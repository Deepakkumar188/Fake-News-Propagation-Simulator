Network Information Dynamics

1. Sparse Adjacency Representation

Social information graphs are strictly sparse, meaning active interpersonal relationships represent a tiny fraction of the total possible edge space ($|E| \ll |V|^2$).

Space Footprint: Ο(V + E) • Neighbor Iteration: Ο(deg(u))

By using an Adjacency List rather than a dense $V \times V$ matrix, memory consumption is minimized and disconnected communities are tracked without wasting allocations on null vectors.

2. Breadth-First Diffusion (Radial Broadcast)

BFS processes information in concentric hop frontiers. An entity at hop distance $k$ receives the transmission before any entity at distance $k + 1$.

  • Computational Complexity: Ο(V + E) deterministic traversal time.
  • FIFO Queue Buffer: Maintains chronological discovery order without priority recalculation.
  • Minimum Hop Optimality: Guaranteed to discover the shortest hop-path from Patient Zero.

3. Depth-First Diffusion (Penetrative Chain)

DFS models high-velocity personal cascades where information travels sequentially down a single chain of forwarders until encountering an infected node or dead end, subsequently backtracking.

  • Computational Complexity: Ο(V + E) traversal time.
  • LIFO Stack Buffer: Prioritizes downstream depth over lateral exploration.
  • Loop Immunity: Visited set prevents infinite forwarding loops along cyclic social rings.

4. Multi-Source Defense (Truth vs. Rumor Race)

Simultaneous multi-source traversal models information containment. When authoritative verification nodes broadcast counter-evidence, their wavefront inoculates uninfected nodes and neutralizes infected ones, halting the viral cascade before critical saturation is reached.

5. Super-Spreader PageRank & Preferential Attachment

The PageRank algorithm models influence via random walks with restart probability $\alpha = 0.85$. In Barabási-Albert scale-free networks, preferential attachment produces hub entities that serve as super-spreaders, enabling rumors to achieve epidemic threshold significantly faster.
